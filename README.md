# arix

Competitive PvP math-based online game 

# PROJECT SETUP
## Front End
- Install NPM and Node.js
- `cd arix-front`
- `npm install`
- `npm run dev`

## Back End
- Install .NET 
- `cd ArixBack`
- `dotnet run`

## Database
- Install Docker
- Make sure you're in the projects root directory
- `docker-compose up -d`

### Recommended Install
- MongoDB database server
- MongoDB Compass (GUI)
- mongosh (TUI)
